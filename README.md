### About me

- I plan and build test automation for web apps and APIs, from the first smoke test to full CI pipelines.
- I care about tests that are fast, readable and stable, and about reports that tell the team what broke and why.
- I have worked with React and Material UI front ends, CI/CD in GitHub Actions and Bitbucket Pipelines, and observability with logs, metrics and tracing.
- Looking for senior or lead QA roles in Stockholm, the Nordics, or remote.
